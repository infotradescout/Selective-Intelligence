## OpenAI Developer Forum showcase post

### Selective Intelligence: correction recovery and verified completion for AI work

Selective Intelligence v1.0.5 is now public in the Plugins Directory.

The core use case is correction recovery: an AI produced the wrong result, the user says what is wrong, and the AI should repair the active understanding and the real work instead of merely apologizing or treating the correction as another feature request.

The plugin also supports sparse briefs, research and source reconciliation, product and UI work, repository audits, interrupted projects, lean context selection, and outcome verification. Ordinary work stays in one context; additional review roles are used only when consequence or an explicit request justifies them.

Starter task:

> Selective Intelligence: inspect this work, find the misunderstanding, fix the real cause, and verify the corrected result.

Public listing: https://chatgpt.com/plugins/plugins_6a89b55ab8e88191addc1c063e779ca7?q=Selective+Intelligence

Pass/fail tests: https://infotradescout.github.io/Selective-Intelligence/try/

Source: https://github.com/infotradescout/Selective-Intelligence

The project is free and CC0. It requires no Selective Intelligence account, payment, API key, or telemetry. Publication is treated as availability evidence only; outside installs and real-task outcomes are being tracked separately through optional redacted feedback.

## 45-second demo script

1. Show a polished AI result that missed the request.
2. Say: “The problem is not that this is ugly. It solved the wrong job.”
3. Open the public Selective Intelligence listing and install it.
4. Paste: “Selective Intelligence: that is not what I meant. Re-read my request and your result, identify the misunderstanding, fix the real cause, and verify the corrected outcome.”
5. Show the changed result and the current proof.
6. End with: “Publication proves it is available. Your result proves whether it helped.”
