# Privacy Policy

Effective August 20, 2026

Selective Intelligence is a skills-only plugin maintained by Platynum Standard.

## Data handling

The plugin provides instructions and local validation utilities. It does not include an MCP server, hosted service, account system, advertising, payments, or analytics. It does not send prompts, files, personal data, or telemetry to Platynum Standard.

When its local feedback feature is used, it stores only privacy-safe outcome signals in the user's own environment. Those signals do not include prompt text or file contents and are not uploaded by the plugin.

The plugin may direct the host AI to use files, websites, connected services, or other tools that the user has already made available. Those products handle data under their own privacy policies and permissions. Selective Intelligence does not expand those permissions.

The plugin does not operate a service database containing user prompts or files.

## Public feedback

Users may optionally submit public feedback through the project's GitHub issue tracker. Anything submitted there is handled by GitHub and may be publicly visible. Do not include secrets, private prompts, personal data, or confidential files in an issue.

## Contact

For privacy questions, open an issue at <https://github.com/infotradescout/Selective-Intelligence/issues>.
