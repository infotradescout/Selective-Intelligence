# Client support

Selective Intelligence has one behavioral source: [`skills/selective-intelligence`](../skills/selective-intelligence/). Clients that support the open Agent Skills format use that directory directly. The generated ChatGPT package changes only packaging because ChatGPT accepts one `SKILL.md` per saved-skill bundle.

[`client-support.json`](client-support.json) records each verified native path, its official documentation, and the client boundary that still applies. It is also the source for the public discovery manifest and site. A client pointer must never become a separate behavioral edition.

[`repository-pointer.md`](repository-pointer.md) is the one short source for generated repository-context pointers. `AGENTS.md`, Copilot instructions, Claude and Gemini imports, and the Cursor rule either match or reference that source. Loading a pointer is never user approval; it only lets a supported client resolve the canonical skill or offer the exact approval question when relevant.

[`indexnow.json`](indexnow.json) defines the public, account-free IndexNow notification for the GitHub Pages path. Its hosted verification file proves control of only that site path. A successful notification proves receipt, not crawling, indexing, ranking, or AI adoption.

The public discovery bridge helps an AI with web access resolve the exact wordmark. It cannot force a client without web or installed-skill discovery to fetch external instructions, and it does not treat publication as adoption evidence.
