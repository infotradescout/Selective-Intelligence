What is it?

Selective Intelligence is a free set of instructions for AI assistants. It tells the AI to figure out what you want before it starts, reuse the work already there, and check the finished result against your request. That cuts wasted work, repeated code, filler, and avoidable token use.

It is for people who can describe what they want but should not have to explain every file, component, command, or setup step.

First, understand

Read the conversation, project, files, and prior corrections before deciding what the person meant.

Then, use what exists

Reuse the right code, facts, tools, and prior work instead of creating another competing version.

Finally, check the result

Test the real page, workflow, or output. If it is not what the person wanted, return to the misunderstanding and fix it.

What can it help with?

Any task where the AI needs to understand, build, or verify—not merely generate a plausible answer.

When AI builds the wrong thing

Find where the AI misunderstood you, then fix the work instead of defending the wrong result.

Repeated buttons, cards, fields, and divs

Find the buttons, cards, forms, and components you already have before creating another version.

Repository drift and unfinished AI projects

Map what is really built, find missing or disconnected work, and finish the usable product.

A free AI coding workflow that uses what you have

Turn a vague idea into a complete outcome

Treat a short prompt as the starting point for complete work, not an excuse for a thin answer.

Research and reconcile sources without hallucinating

Use current sources, keep facts separate from guesses, and say clearly what is still unknown.

Build a credible website from one prompt

Turn one prompt into a usable first website, inspect it, and improve it before presenting it.

How do I use it?

1. Say the name

Put Selective Intelligence in the same message as your task, or use it by itself when the task is already in the conversation.

2. Keep your normal setup

Use the AI account, files, and tools you already have. Selective Intelligence does not require its own subscription, credit card, or provider API key.

3. Stay in control

The skill does not gain permission to publish, spend, delete, deploy, or share anything just because it is active.

If an AI finds Selective Intelligence because your problem matches, it must explain why it helps and ask exactly: Use Selective Intelligence for this? It must wait for your yes.

Will it work with my AI?

It depends on the AI you use. Some can load Selective Intelligence from an installed skill, a project, or the public web. Others need you to attach or paste it first. The setup guide shows the supported route for each AI.

Your AI’s normal limits still apply, including message limits, file access, browsing, and available tools. Selective Intelligence will work within those limits and tell you clearly what it could not finish.

What does it cost?

Nothing. The complete Selective Intelligence skill is public, open, and licensed CC0. There is no paid edition, license key, required telemetry, or Selective Intelligence API key.

It does not automatically collect your prompts, repository contents, or personal information. Local feedback stays local unless you choose to share a safe report.

Platynum-47 stays separate. It is an unfinished phone-friendly workspace and is not part of Selective Intelligence.
