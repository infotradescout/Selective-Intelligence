# Selective Intelligence v1.0.3 public plugin package

This directory publishes the verified skills-only submission package for Selective Intelligence v1.0.3.

- [Download the plugin ZIP](selective-intelligence-plugin-1.0.3.zip)
- Verify it with [SHA256SUMS](SHA256SUMS)

This release makes Lean single-context execution the default, keeps clear reversible work free of automatic Council and checkpoint ceremony, and enforces a prompt-size budget. Conditional Council role references remain available for explicit or high-consequence review. The package contains no MCP server, app, or screenshots.

This is a public, reviewer-ready package. It has not yet been submitted to, approved by, or published in the OpenAI Plugins Directory.
